# Wordle — CS Edition (Plain HTML/CSS/JS)

This is a simple Wordle clone built with plain HTML, CSS and JavaScript (no frameworks).

How to run
- Open `index.html` in your browser (double-click or `open index.html` on macOS).

Notes
- The word dataset is a list of elementary CS-related 5-letter words embedded in `script.js`.
- It's intentionally simple so you can showcase it to a teacher.

Feel free to ask me to: add scoring, keyboard animations, or package it for deployment.
